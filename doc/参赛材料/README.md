# 参赛材料

本目录保存第八届中国研究生人工智能创新大赛的正式文档源文件和生成结果。

## 文件

| 文件 | 用途 |
|---|---|
| `作品简介.md` | 273 字作品简介源文件 |
| `智航灵枢_参赛作品简介.docx/.pdf` | 简介提交稿 |
| `翼策_项目文档.md` | V2.0 正式版项目文档源文件 |
| `翼策_项目文档.docx/.pdf` | **本轮项目文档提交稿**（初赛正式版） |
| `智航灵枢_项目文档.md/.docx/.pdf` | V1.1 校内选拔历史稿，仅供追溯 |
| `智航灵枢_校内选拔汇报.pptx/.pdf` | 10 页校内答辩汇报稿 |
| `素材/地面站界面_任务闭环.png` | Web 地面站真实界面截图 |
| `提交检查清单.md` | 身份信息、真实性、隐私和文件检查 |
| `build_作品简介.py` | 生成简介 DOCX/PDF |
| `build_项目文档.py` | 从 Markdown 生成项目文档 DOCX/PDF |
| `build_校内选拔PPT.py` | 生成校内答辩 PPTX |

## 生成

```bash
cd ~/aeromind_ws
python3 -m pip install --user -r doc/参赛材料/requirements.txt
python3 doc/参赛材料/build_作品简介.py
python3 doc/参赛材料/build_项目文档.py
python3 doc/参赛材料/build_校内选拔PPT.py
```

## 提交前检查

1. 官网项目文档模板要求封面包含团队名称与参赛组别；当前团队名使用“翼策项目团队”，上传前须与报名系统逐字核对。
2. 修改 `翼策_项目文档.md` 后，重新执行 `build_项目文档.py` 生成 DOCX/PDF。
3. 按 `提交检查清单.md` 复核 PDF、视频、文件名、身份信息与隐私。
4. 最终文件名应为“团队名称_项目名称_项目文档.pdf”。

不得把 AirSim/PX4 仿真结果写成真机实验，也不得把 Agent 离线规划准确率写成
无人机飞行成功率。
