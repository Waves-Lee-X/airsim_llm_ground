# 参赛材料

本目录保存第八届中国研究生人工智能创新大赛的正式文档源文件和生成结果。

## 文件

| 文件 | 用途 |
|---|---|
| `作品简介.md` | 298 字作品简介源文件 |
| `智航灵枢_参赛作品简介.docx/.pdf` | 简介提交稿 |
| `智航灵枢_项目文档.md` | 按大赛模板组织的项目文档源文件 |
| `智航灵枢_项目文档.docx/.pdf` | 项目文档提交稿 |
| `提交检查清单.md` | 身份信息、真实性、隐私和文件检查 |
| `build_作品简介.py` | 生成简介 DOCX/PDF |
| `build_项目文档.py` | 从 Markdown 生成项目文档 DOCX/PDF |

## 生成

```bash
cd ~/aeromind_ws
python3 -m pip install --user -r doc/参赛材料/requirements.txt
python3 doc/参赛材料/build_作品简介.py
python3 doc/参赛材料/build_项目文档.py
```

## 提交前修改

1. 在 `智航灵枢_项目文档.md` 中填写团队、学校、成员、导师、硬件和分工。
2. 在 `build_项目文档.py` 顶部同步修改 `TEAM`、`SCHOOL`、`GROUP` 等封面字段。
3. 重新执行两个生成脚本。
4. 按 `提交检查清单.md` 检查 PDF、视频、文件名和敏感信息。
5. 最终文件名使用报名系统中的正式团队名称。

不得把 AirSim/PX4 仿真结果写成真机实验，也不得把 Agent 离线规划准确率写成
无人机飞行成功率。
