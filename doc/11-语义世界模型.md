# 语义世界模型

本模块把 YOLO 的二维检测、深度图、相机内参和 ROS TF 融合为结构化三维对象，为 Agent、态势地图和后续动态避障提供统一的环境事实。

本文说明已实现功能；后续完整工作包和验收计划见 [语义世界模型升级计划](12-语义世界模型升级计划.md)。

## 1. 当前实现

`semantic_fusion_node` 订阅：

- `/perception/detections`：YOLO 类别、置信度和二维检测框。
- `/sensor/camera/rgb/front_center`：提供原始图像尺寸。
- `/sensor/camera/depth/front_center`：在检测框中心区域计算中值深度。
- `/sensor/camera/depth/front_center/camera_info`：将像素反投影到相机坐标系。
- `/tf`：将相机坐标转换到 `odom` 世界坐标系。

节点发布 `/world_model/objects` (`SemanticObjectArray`)，包含短时稳定 ID、类别、置信度、三维位置、深度、速度、动态标记、数据年龄和证据来源。

深度或 TF 不可用时，对象仍可作为二维观测发布，但 `position_valid=false`，不应用于三维距离决策。

## 2. 启动与验证

PX4 主 Launch 默认启动语义融合节点；需要 YOLO 提供对象输入：

```bash
ros2 launch aeromind_bringup aeromind_px4.launch.py \
  yolo_enabled:=true semantic_world_enabled:=true
```

检查数据：

```bash
ros2 topic hz /world_model/objects
ros2 topic echo /world_model/objects --once
ros2 run tf2_ros tf2_echo odom camera_front_center_optical
```

Web 态势地图会显示具有有效三维位置的语义对象。Agent 感知摘要会返回 `world_objects` 及证据来源。

## 3. 当前边界

- 当前是局部短时对象模型，不是全局持久化 SLAM 语义地图。
- 目标关联使用类别和三维近邻，尚未接入 ByteTrack/ReID。
- 速度来自短时差分和滤波，不能替代成熟的多目标跟踪器。
- 前视深度只覆盖相机视场，“未观测”不等于“不存在”。
- 语义对象已用于 Agent 查询和 Web 展示，尚未作为动态障碍直接绑定到轨迹规划器。

## 4. 后续顺序

1. 接入 ByteTrack/BoT-SORT 和三维卡尔曼滤波，提高 ID 和速度稳定性。
2. 使用 VIO/SLAM 的 `map` 坐标系，持久化对象与观测历史。
3. 增加语义区域和场景关系，建立可查询场景图。
4. 将动态对象预测位置接入局部重规划，进行时空避障。
5. 增加人员进入航线时悬停、拍照，离开后恢复任务的事件闭环。
