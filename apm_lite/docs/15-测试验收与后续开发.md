## 3. 分级调试路线

必须按级别推进；前一级失败时不进入后一级。

### L0：纯软件检查

目标：不启动 UE、SITL、串口或模型。

1. 运行完整测试。
2. 检查 Schema 导出。
3. 检查 JS 语法和文档链接。
4. 确认没有真实密钥进入 Git。

通过条件：全部自动测试通过，工作区只有预期改动。

### L1：DEMO 地面站

```bash
PYTHONPATH=src python3 -m aeromind_apm_lite.ground.browser.app \
  --mode demo --host 127.0.0.1 --port 8010 --disable-camera
```

检查页面布局、状态刷新、模拟命令证据、Mission Agent 对话和草案确认。通过条件：
页面无重叠，API 正常，所有命令明确标记模拟，不产生 MAVLink。

### L2：手动 AirSim/SITL

1. 重新生成 `settings.json`。
2. 启动 UE 场景并 Play。
3. 在独立目录启动 ArduCopter SITL。
4. 启动 `--mode sitl` 地面站。
5. 确认 FCU、GPS、EKF、Home 和相机。
6. 按 ARM -> TAKEOFF -> HOLD -> LAND 测试。
7. 单独测试 RTL。

通过条件：每条命令三层证据完整，LAND/RTL 最终落地加锁。

### L3：导航和故障注入

运行一份基线及：

```text
gps_loss
hdop_exceeded
ekf_failure
mission_expired
ground_link_loss
```

通过条件：基线完成；五类故障均进入预期 `safety_hold -> recovery_land`，且证据文件
绑定软件、飞控、场景和标定版本。

### L4：UAV3 实机只读

前提：拆桨、固定机体、独立供电、RC 可接管。

1. 树莓派确认两个服务和 UART 所有者。
2. Windows 启动 `real_serial` 地面站。
3. 检查 FCU/P9/RGB，不调用命令接口。
4. 运行 60 秒验收：

```powershell
& "$env:USERPROFILE\.aeromind\venv\Scripts\python.exe" `
  .\deploy\windows\accept-real-closure.py --duration 60
```

通过条件：Agent/FCU 持续在线，帧持续增长，CRC/重试/无效负载不持续增长，服务没有
重启。

### L5：无桨 ARM/DISARM

除 L4 外还必须确认：

```text
command_output_enabled=true
allowed_commands=[arm, disarm]
armed=false
prearm_ok=true
```

人工只执行一次 ARM，确认应用、MAVLink、`armed=true`；随后立即 DISARM 并确认
`armed=false`。任何拒绝都保留原始证据，不强制解锁。

### L6：室外静态与低空

当前尚未执行。顺序应为：

1. 静态 GPS Fix/HDOP/Home/EKF 记录；
2. RC 接管和 failsafe；
3. 场地原点、方向和四机 Home 实测；
4. 冻结 `surveyed` GeoReference；
5. 单机低高度垂直起降；
6. 单机短航点；
7. 记录 observed 轨迹并与 SITL 比较；
8. 双机到四机逐级扩大。

未完成 L6 前不得开放实机 GOTO、编队和路径规划。

## 4. 一次调试应保存什么

每次有效验收至少保存：

- 日期、操作者、飞机编号和地点；
- Lite Git 提交；
- ArduCopter 版本和参数哈希；
- UE 场景/AirSim 版本；
- GeoReference ID 和哈希；
- 地面 `/api/status` 快照；
- 树莓派服务日志；
- 命令三层证据；
- planned/predicted/observed 轨迹；
- VLM 使用的图像、提示词、模型和原始返回；
- 异常、人工接管和恢复过程。

## 5. 当前下一步

在无法外场飞行的条件下，软件开发按以下顺序继续：

1. M4：视觉帧和模型结果持久化、多帧一致性、OpenCV 颜色交叉验证；
2. M5：四个 SITL/Agent、三种队形、最小间距和掉队策略；
3. M6：已知场地全局路径、轨迹安全检查和 D435 可选安全停止层；
4. M7：箱体编号/颜色/面多帧识别、语义世界更新和目标重分配；
5. 外场条件具备后穿插完成 L6，不得用仿真结果替代。
