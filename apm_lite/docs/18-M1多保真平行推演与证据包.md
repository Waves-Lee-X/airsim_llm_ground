# M1 多保真平行推演与证据包验收记录

## 1. 范围

本记录对应升级方案的 M1 最小版，覆盖：

- WP1：统一孪生状态、静态能力档案、任务图、世界事件、策略和指标契约；
- WP2：L0 事件级模型、内容寻址分支、四类受约束策略和方向感知 Pareto 优选；
- WP6：实验锁定、产物索引、SHA-256 校验、目录/ZIP 导出和独立验证。

L0 只用于方案广筛。它不替代 L2 SITL、硬件在环或真机验收，也不改变现有飞控命令链。
AI 辅助策略只产生约束内参数，不能直接控制飞控。

## 2. 统一对象

`TwinState` 使用现有 `CoordinateFrame` 和整数 `vehicle_id`，并强制标注：

- `source=sim` / `source=real` / `source=predicted` / `source=observed`；
- `fidelity=L0` 至 `L3`；
- 采样时间，以及仿真时间和映射时间中的一种。

`VehicleRegistry` 以 JSON 原子写入保存档案和最新状态，支持能力、电量、通信质量、位置和
白名单级别查询。注册表查询只返回数据，不发送命令。

## 3. 最小演示链

```text
统一基线快照
  -> 内容寻址分支（事件差分 + 策略 + 种子）
  -> L0 四策略并行评估
  -> 安全硬约束淘汰
  -> 任务完成率/安全距离/耗时/能耗/通信/恢复能力
  -> Pareto 前沿
  -> EvidencePackage（JSON + Markdown + SHA-256）
```

运行 256 对象、32 分支演示：

```bash
cd ~/aeromind_ws/apm_lite
PYTHONPATH=src python3 -m aeromind_apm_lite.ground.deduction.cli demo \
  --vehicles 256 --branches 32 --seed 20260810 --workers 4 \
  --output /tmp/aeromind-m1-run.json \
  --evidence /tmp/aeromind-m1-evidence.zip
PYTHONPATH=src python3 tools/export_evidence.py verify /tmp/aeromind-m1-evidence.zip
```

## 4. 实测结果

2026-08-10 在 WSL Python 3.10 环境执行：

| 项目 | 结果 | 口径 |
|---|---:|---|
| 同种子重复 10 次终态一致率 | 100% | `reproducibility_hash` 和终态逐项一致 |
| 压力规模 | 256 对象 / 32 分支 | L0 事件模型，4 workers |
| L0 仿真时间/墙钟时间 | 10011.37x | `simulated_time_s / wall_time_s`，不是 L2 加速比 |
| Pareto 输出 | 20 个可行前沿分支 | 其余分支按硬约束和支配关系筛选 |
| 证据包校验 | 通过 | manifest、产物大小和 SHA-256 全部通过 |
| Lite 自动测试 | 334 项通过 | `PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 python3 -m pytest -q tests` |

该加速指标只描述 L0 离线事件模型相对墙钟的吞吐；L0/L1 与 L2 SITL 的跨保真排名一致性
需要后续接入高保真复验后单独报告，当前不作真机结论。
