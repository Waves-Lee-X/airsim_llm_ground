## 2. 坐标约定

- 所有槽位偏移定义在**场地地图坐标（map）**：`x` 为北向（机头方向），`y` 为东向，单位米。
- 编队参考点是领机目标点：`每机目标 = 领机目标 + 槽位偏移`。
- 高度统一取领机目标高度，队形只在水平面变化。

## 3. 三种队形

| 队形 | 说明 | 槽位生成 |
|---|---|---|
| `line` 一字横队 | 与机头垂直的一排 | `(0, (i-(n-1)/2)*间距)` |
| `v` V 字队形 | 奇数架：领机在顶点；偶数架：完全对称双翼（顶点无机） | 第 k 排左/右翼 `(-k·d·cos45°, ∓k·d·sin45°)`，左右成对生成 |
| `diamond` 正方形 | 2×2 四角（间距=边长）；5 机时中心+四角 | 四角 `(±s/2, ±s/2)`；5 机中心距角=间距 |

所有队形保证任意两槽位距离 ≥ 间距（默认 3 m），由 `validate_spacing` 强制校验。

## 4. 平滑切换

`transition_offsets(from, to, n, spacing, progress)`：

- 槽位序号保持不变，每架飞机只在自己的槽位内插值移动；
- `progress ∈ [0,1]`，线性插值；`0` 为旧队形、`1` 为新队形；
- 切换全程调用 `validate_trajectory_separation` 做**时空碰撞检查**，发现轨迹间距小于安全值即拒绝切换。

## 5. 槽位分配

`assign_slots(vehicle_ids, positions, offsets)`：

- 按当前位置到槽位的欧氏距离做**确定性贪心就近分配**（距离、机号、槽位号三级稳定排序）；
- 相同输入永远得到相同分配，便于测试与回放。

## 6. 时空碰撞检查

`validate_trajectory_separation(trajectories, min_distance_m)`：

- 对任意两条轨迹的每一对线性段，计算它们在**重叠时间段内**的最近三维距离（解析解，含端点与极值点）；
- 最近距离低于安全值即抛出 `FleetPlanError`，不产生任何指令。

## 7. 机队决策（FleetCoordinator）

输入每机的 `ready / link_ok / last_seen_age / 位置`，输出每机数据指令（`goto/hold/land/rtl`），不直接连接飞控：

| 状态 | 行为 |
|---|---|
| 全部就绪 | 按队形槽位下发 `goto`（`formation_hold`） |
| 过渡中 | 插值槽位下发 `goto`（`transit`） |
| 有飞机未就绪 | 全部 `hold`（`syncing`），等待同步开始 |
| 遥测过期（> `sync_timeout_s`） | 全部 `hold`（`syncing`） |
| 单机失联（> `lost_timeout_s`） | 允许降级时：剩余机按缩编队形继续（`degraded`）；否则全部 `hold`（`aborted`） |

## 8. 四机仿真启动配置

`fleet_launch_config(vehicle_count=4, spacing_m=3.0)` 生成：

- 4 个 SITL 实例：`Drone1..Drone4`，MAVLink 系统号 1..4；
- 独立 MAVLink 端口（14550 起按实例 +10）、AirSim 传感器/控制端口；
- 初始位置按一字横队间距 3 m 摆放，避免起飞前机间干扰；
- 所有实例共享同一地理 Home，用 `initial_pose` 表达相对偏移。

## 11. Web 编队面板（2026-07-31）

- 右侧控制区新增"编队"面板：队形选择（一字/V 字/正方形）、领机目标 X/Y/Z、间距与切换进度由后端 FleetService 管理。
- `GET /api/fleet/status`：返回当前队形、阶段（syncing/transit/formation_hold/degraded/aborted/idle）、每机指令（动作/槽位/目标/原因）。
- `POST /api/fleet/formation`：设置队形、领机目标、间距、切换进度与参与机集合；非法值返回 422。
- 编队面板**只做规划预览**（`preview_only=true`），不直接下发 MAVLink；实机执行仍需现有白名单与人工确认门禁。
- 未注册/从未连上的飞机显示"同步中"等待，不触发失联中止；只有"曾在线后超过 lost_timeout 未回"的飞机才按失联处理（降级或中止）。
