## 2. 场景与结果

### 2.2 Agent 端到端闭环

- 指令："1号机起飞到3米，识别橙色球体，停在球体外侧5米处，机头朝向球体，到达后悬停"
- Agent 计划：`arm + takeoff(3m) + analyze(navigate_after, standoff_distance_m=5) + hold`
- 执行：起飞 → 目标发现（画面边缘）→ 迭代对准 → 深度定位 → 停靠 → 悬停 → 反馈 completed
- 会话中草案状态：`completed`
