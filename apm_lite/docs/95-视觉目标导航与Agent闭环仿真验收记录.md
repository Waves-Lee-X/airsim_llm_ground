# 95 视觉目标导航与 Agent 闭环仿真验收记录

> 日期：2026-08-01；环境：AirSim Blocks + ArduCopter SITL ×4（fleet-m5-run1 参数）。

## 1. 验收内容

- Agent 端到端闭环：自然语言指令 → 计划 → 人工确认 → 自动执行 → 结果反馈。
- 深度相机精确停靠：停在目标外侧指定距离。
- 旋转搜索、迭代对准、安全护栏。

## 2. 场景与结果

验证方式：停靠后再次分析，读取深度相机到球表面的距离。

### 2.2 Agent 端到端闭环

- 指令："1号机起飞到3米，识别橙色球体，停在球体外侧5米处，机头朝向球体，到达后悬停"
- Agent 计划：`arm + takeoff(3m) + analyze(navigate_after, standoff_distance_m=5) + hold`
- 执行：起飞 → 目标发现（画面边缘）→ 迭代对准 → 深度定位 → 停靠 → 悬停 → 反馈 completed
- 会话中草案状态：`completed`

## 4. 综合任务演示修复与重验（2026-08-01）

### 4.1 现象

四机"一字编队 + 2 号机视觉停靠"综合演示复测失败：2 号机最终画面里没有球体
（球在机身左后方约 127°），系统却报告完成。

### 4.2 根因与修复

- 重定位固定向目标靠近 5 m，球体占满画面（覆盖率 93.9%）后 VLM 失明，
  深度目标被可达性检查丢弃，落入"朝目标方向盲飞 15 m"兜底路径；
- 兜底路径无机头朝向、无最终画面校验，直接悬停造成假成功。
- 修复（`mission_planner.py`）：重定位步长按停靠距离收缩；兜底 goto 带朝向；
  兜底后强制最终视觉校验（目标居中 + 重新深度停靠，否则失败）；
  目标覆盖率 >55% 自动后退。详见 `docs/17` 第 10 节。

### 4.3 重验结果

- 指令："四机起飞到 3 米，一字编队飞往 (27.5, 30.2) 保持，2 号机识别橙色球体
  并停在球体外侧 5 米，最后全部悬停"（Agent 闭环，人工确认后执行）。
- 执行：11 步全部完成（4 上锁 + 4 起飞 + 一字编队 + 2 号机深度停靠 + 全队悬停），
  计划状态 `completed`，无报错。
- 2 号机最终画面包含球体（橙色覆盖率 36%、位于画面中央），机头朝向偏差 2.8°，
  停靠表面距离约 7 m（目标 5 m）。
- 门禁：`312 passed`；flake8 无新增告警。
- 待办：起飞步骤重试机制（刚重启飞控时 NAV_TAKEOFF 可能被静默忽略）；
  停靠距离误差校准（深度像素采样/球体半径估计）。
