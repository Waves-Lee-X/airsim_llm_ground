# AeroMind Console 改进计划

## 1. 项目定位

**AeroMind Console** 是一个面向 AirSim / UE 仿真的大模型无人机任务控制台。它不再以传统地面站的“按钮控制”为核心，而是以“自然语言任务驱动”为核心，让用户通过文本或语音描述任务，由系统完成任务理解、路径规划、飞行控制、视觉检测、避障和任务报告。

项目目标可以概括为：

> 让无人机从“被手动控制”升级为“被任务驱动”。

典型演示场景：

> 用户输入：“搜索前方 60 米区域，发现车辆后悬停并报告坐标。”
>
> 系统解析任务，生成搜索路径，控制无人机起飞，调用摄像头识别车辆，发现目标后悬停并输出坐标和截图。

## 2. 当前状态

当前已经完成：

- 独立项目目录：`AeroMind Console`
- Web 主界面原型
- 自然语言任务输入区
- 任务模板：区域搜索、目标扫描、编队飞行
- 大模型任务计划展示区
- 任务事件流
- 视频画面占位区
- 少量安全操作：暂停、返航、终止
- 轻量 HTTP 服务：`server.py`
- 演示 API：
  - `/api/state`
  - `/api/task/preview`
  - `/api/task/run`
  - `/api/task/pause`
  - `/api/task/stop`
  - `/api/task/rtl`

当前主要不足：

- 视频区还没有接入 AirSim / UE 实时画面。
- 任务规划仍是演示规则，没有接入真实大模型。
- 任务还没有真正驱动 AirSim 无人机执行。
- 视觉检测框是模拟效果，还没有接入 YOLO / 多模态识别。
- 语音入口是预留交互，还没有接入语音识别。
- 缺少完整任务报告和演示闭环。

## 4. 功能模块设计

### 4.1 视频与仿真画面模块

目标：让左侧主画面显示真实 AirSim / UE 画面，提升演示可信度。

优先实现方案：

- 使用 AirSim Image API 获取前视摄像头图像。
- 后端提供 MJPEG 视频流：
  - `GET /video/front`
  - `GET /api/camera/snapshot`
- 前端使用 `<img>` 或 canvas 显示实时画面。
- 在画面上叠加 HUD：
  - UAV 编号
  - 高度
  - 速度
  - 坐标
  - 当前任务步骤
  - 目标检测框

后续增强：

- 接入 UE Pixel Streaming。
- 支持多视角切换：
  - 前视摄像头
  - 俯视摄像头
  - 追踪视角
  - 地图视角

### 4.2 自然语言任务规划模块

目标：把用户输入转成结构化任务。

输入示例：

```text
搜索前方 60 米区域，发现车辆后悬停并报告坐标。
```

输出结构：

```json
{
  "intent": "area_search",
  "target": "vehicle",
  "area": {
    "x_min": 0,
    "x_max": 60,
    "y_min": -20,
    "y_max": 20
  },
  "altitude_m": 8,
  "strategy": "lawnmower",
  "on_detect": {
    "action": "hover_and_report",
    "report_coordinate": true,
    "save_snapshot": true
  }
}
```

第一阶段：

- 使用规则解析实现常见任务。
- 支持中文关键词：
  - 搜索
  - 扫描
  - 车辆
  - 行人
  - 建筑
  - 避障
  - 编队
  - 返航

第二阶段：

- 接入真实大模型。
- 要求大模型输出严格 JSON。
- 对大模型输出做 schema 校验。
- 无效任务需要提示用户修正。

### 4.3 任务执行模块

目标：把结构化任务转换成 AirSim 控制动作。

核心类建议：

```text
core/task_executor.py
```

职责：

- 管理当前任务状态。
- 调用 AirSim 控制接口。
- 执行任务步骤。
- 写入事件流。
- 支持暂停、恢复、终止、返航。

第一批任务：

- 起飞
- 降落
- 悬停
- 返航
- 飞到指定坐标
- 区域搜索
- 航点巡航

区域搜索执行流程：

1. 起飞到目标高度。
2. 生成蛇形搜索路径。
3. 飞到搜索起点。
4. 按路径巡航。
5. 每隔固定时间读取摄像头图像。
6. 调用视觉检测模块。
7. 发现目标后悬停并记录坐标。
8. 生成任务报告。

### 4.4 路径规划模块

目标：支持从自然语言任务生成可执行飞行路径。

第一阶段路径类型：

- 单点导航
- 航点任务
- 矩形区域蛇形覆盖
- 绕目标环绕扫描

区域搜索路径示例：

```text
(0, -20) -> (60, -20)
(60, -10) -> (0, -10)
(0, 0) -> (60, 0)
(60, 10) -> (0, 10)
(0, 20) -> (60, 20)
```

后续增强：

- 加入障碍物代价地图。
- 加入 A* / RRT / DWA 等路径规划算法。
- 根据 LiDAR 或深度图动态避障。

### 4.5 视觉检测模块

目标：让无人机具备“看见目标”的能力。

可复用资源：

- `Airsim_Yolov5_ODRT-master`
- `yolov5s.pt`
- `yolov8n.pt`

第一阶段：

- 接 AirSim 摄像头帧。
- 调用 YOLO 检测车辆、行人等目标。
- 返回检测结果：

```json
{
  "detections": [
    {
      "label": "car",
      "confidence": 0.82,
      "bbox": [120, 80, 260, 210]
    }
  ]
}
```

前端展示：

- 视频画面叠加检测框。
- 显示目标类别和置信度。
- 事件流记录发现目标。

第二阶段：

- 根据目标框和无人机位姿估计目标位置。
- 保存目标截图。
- 生成任务报告。

### 4.6 语音控制模块

目标：支持通过语音下达任务。

第一阶段：

- 使用浏览器 Web Speech API。
- 识别中文语音。
- 自动填入任务输入框。
- 用户确认后执行。

第二阶段：

- 后端接 ASR 模型。
- 支持离线语音识别。
- 增加唤醒词：
  - “智航，开始搜索”
  - “智航，返航”

### 4.7 多机与编队模块

目标：提升项目深度和展示效果。

支持任务：

- 多机同步起飞。
- V 字编队。
- 横队编队。
- 纵队编队。
- 多机分区搜索。

自然语言示例：

```text
三架无人机组成 V 字编队，沿 X 轴前进 40 米，并保持避障。
```

执行逻辑：

1. 大模型解析编队类型和参与无人机数量。
2. 分配领机和跟随机。
3. 计算每架无人机相对位置。
4. 控制领机执行主路径。
5. 跟随机保持队形。

## 5. 页面交互改进计划

### 5.1 主界面

继续保持当前设计方向：

- 左侧：视频 / 仿真画面为第一视觉。
- 右侧：自然语言任务和大模型计划。
- 底部：任务状态、坐标、进度、事件流。

后续增强：

- 视频画面接入真实摄像头流。
- 检测框显示真实检测结果。
- 当前任务步骤在画面 HUD 中同步显示。
- 任务完成后弹出报告面板。

### 5.2 任务体验

增强点：

- 任务模板可配置。
- 用户输入任务后自动预解析。
- 执行任务前展示“任务确认卡片”。
- 任务执行中显示：
  - 当前步骤
  - 剩余步骤
  - 当前目标
  - 是否发现目标
  - 是否触发避障

### 5.3 安全体验

保留少量但重要的安全操作：

- 暂停
- 返航
- 终止

不要在主界面堆叠传统按钮。

调试按钮可以放在隐藏面板：

- 解锁
- 上锁
- 起飞
- 降落
- 指点飞行
- 手动航点

## 8. 最终演示脚本

推荐展示流程：

1. 打开 AeroMind Console。
2. 左侧显示 AirSim 无人机摄像头画面。
3. 点击“区域搜索”任务模板。
4. 修改或语音输入：

```text
搜索前方 60 米区域，发现车辆后悬停并报告坐标。
```

5. 点击“预览计划”。
6. 页面显示任务拆解：
   - 理解搜索目标
   - 生成覆盖路径
   - 起飞并进入区域
   - 视觉检测闭环
   - 目标确认与悬停
7. 点击“执行任务”。
8. 无人机起飞并按蛇形路径搜索。
9. 摄像头画面出现车辆检测框。
10. 事件流显示发现目标。
11. 无人机悬停。
12. 系统生成任务报告：目标类别、置信度、坐标、截图。

## 9. 优先级建议

最高优先级：

1. 接入 AirSim 摄像头画面。
2. 实现区域搜索任务执行。
3. 接入目标检测。

中优先级：

1. 接入真实大模型。
2. 语音控制。
3. 任务报告。

低优先级：

1. 多机编队完整闭环。
2. UE Pixel Streaming。
3. 复杂路径规划算法。

## 10. 项目亮点总结

- 不是传统按钮式地面站，而是任务驱动控制台。
- 用户通过自然语言或语音控制无人机。
- 大模型负责理解和规划。
- AirSim 负责仿真和飞行控制。
- 视觉模型负责目标识别。
- 前端展示完整任务过程和结果。

最终目标：

> 打造一个“能看见、能理解、能规划、能执行、能报告”的大模型无人机任务控制台。
