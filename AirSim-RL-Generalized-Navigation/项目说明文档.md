# 无人机自主导航系统改进说明

## 1. 项目概述

本项目实现了一个基于强化学习的无人机自主导航系统，能够在模拟环境中实现目标点导航和障碍物避障。系统使用SAC（Soft Actor-Critic）算法进行训练，结合专家策略引导，提高了导航和避障的性能。

## 2. 核心改进

### 2.1 安全检测与避障动作强化

**改进内容：**
- **扩大安全检测距离**：将障碍物检测阈值从2.0米增加到3.0米，提供更多反应时间
- **添加多级别警告**：
  - 危险区（<1.5米）：触发紧急后退动作
  - 警告区（1.5-3.0米）：准备避障
  - 预警区（3.0-5.5米）：开始避障操作
- **加强避障动作**：
  - 增加避障移动速度和幅度（从1.0/1.5提高到1.5/2.0）
  - 延长避障冷却时间（从10秒增加到15秒）
  - 增强后退动作力度（从-1.5提高到-2.0）
- **实时距离监控**：检测距离连续减少时触发紧急避障

**代码实现：**
- 在`ExpertPolicy.expert_action`方法中实现了多级别的障碍物检测和避障策略
- 增加了距离历史记录和分析，实现了距离变化的实时监控

### 2.2 路径记忆与回归机制

**改进内容：**
- **路径记忆**：记录最近30个位置和动作，用于分析路径模式
- **避障方向历史**：记录最近10次避障方向，避免重复相同的避障动作
- **路径回归**：绕过障碍物后自动回归到目标方向
- **方向切换机制**：当重复相同避障方向5次以上时，强制切换方向

**代码实现：**
- 添加了`distance_history`和`avoid_direction_history`属性
- 实现了避障方向重复检测和强制方向切换
- 增强了路径回归逻辑，确保在避开障碍物后回到正确路径

### 2.3 障碍物预测优化

**改进内容：**
- **增强卡尔曼滤波器**：同时预测位置、速度
- **多时间步预测**：预测0.5秒、1.0秒、2.0秒后的障碍物位置
- **预测置信度**：基于滤波器协方差矩阵计算预测的可靠性
- **多假设预测**：考虑多种可能的障碍物轨迹

**代码实现：**
- 重写了`predict_obstacle_position`方法，实现了多时间步预测
- 添加了预测置信度计算和多时间步预测结果打印

## 3. 系统架构

### 3.1 环境组件

- **AirSimDroneEnv**：基于Gymnasium的无人机环境，提供状态观察和动作执行
- **ExpertPolicy**：专家策略，提供避障和导航的启发式规则
- **SACAgent**：强化学习智能体，使用SAC算法进行训练

### 3.2 状态表示

状态向量包含13个维度：
- 无人机当前位置（x, y, z）
- 目标位置（x, y, z）
- 前方障碍物距离
- 左侧和右侧可用空间
- 障碍物速度（x, y）
- 障碍物左右边缘位置

### 3.3 动作空间

动作向量包含3个维度：
- 前进/后退速度（vx）
- 左右移动速度（vy）
- 高度调整速度（vz，固定为0）

## 4. 使用方法

### 4.1 训练模型

```bash
python Train1.py
```

训练过程中，系统会：
1. 初始化环境和智能体
2. 提示用户选择目标位置（默认或自定义）
3. 开始训练，每50个回合保存一次模型
4. 训练完成后保存最终模型

### 4.2 目标位置设置

训练开始时，用户可以选择：
- 选项1：使用默认目标位置（71.7, 11.6, -2.0）
- 选项2：自定义目标位置，输入X和Y坐标

### 4.3 模型加载与使用

```python
from UAV_Autonomous_navigation import AirSimDroneEnv, SACAgent

# 初始化环境和加载模型
env = AirSimDroneEnv()
agent = SACAgent(state_dim=13, action_dim=3)
agent.load("sac_model_final.pth")

# 设置新的目标位置
env.set_target_position([x, y, -2.0])

# 开始导航
state, _ = env.reset()
while True:
    action = agent.select_action(state)
    next_state, reward, terminated, truncated, info = env.step(action)
    state = next_state
    if terminated or truncated:
        break
```
