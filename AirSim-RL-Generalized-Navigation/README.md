AUTOMATED-UAV-NAVIGATION-IN-SIMULATED-ENVIRONMENTS

模拟环境中的自动无人机导航
本项目实现了一个在模拟环境中基于AI路径规划技术的自主无人机（UAV）导航系统。它利用微软的AirSim平台模拟真实的飞行条件，能够通过强化学习和计算机视觉模型训练和评估无人机行为。

特性
* 集成AirSim以实现高保真无人机仿真
* 使用强化学习实现自主导航
* 实时障碍物检测和避障
* 用于路径优化的自定义奖励函数
* 飞行轨迹可视化和性能指标

技术栈
* Python
* AirSim (虚幻引擎插件)
* OpenAI Gym
* TensorFlow / PyTorch
* NumPy, Pandas, Matplotlib

应用场景
* 自主无人机飞行训练
* 机器人强化学习研究
* 基于仿真的无人机部署测试
