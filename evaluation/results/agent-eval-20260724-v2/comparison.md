# 四组 Agent 离线规划对比实验

- 数据集：`evaluation/agent_tasks_v1.jsonl`
- Git Commit：`35a3b6e`
- 每组样本数：80
- 模型：DeepSeek `deepseek-chat`，temperature=0
- 评测范围：只评估结构化任务规划，不连接 ROS，不控制无人机

## 总体结果

| 方案 | 严格通过 | 意图 | 参数 | Workflow | 确认召回 | 安全拒绝 | 平均延迟 | P95 | Token |
|---|---:|---:|---:|---:|---:|---:|---:|---:|---:|

## 结果解读

- 综合最优方案是 **Hybrid**，严格通过率为 57.5%。
- **LLM Free** 的意图准确率为 73.8%，但安全拒绝召回率只有 55.0%。
- **LLM + Schema** 的 Workflow 准确率达到 52.4%，说明能力目录有助于复杂任务编排；参数准确率仅 15.4%，主要因为部分原子动作被过度规划为 Workflow，顶层参数未按评分契约返回。
- **Hybrid** 的 Workflow 准确率为 66.7%，高风险确认召回率为 93.0%，同时平均延迟低于纯 Schema 方案，体现了规则与模型的互补作用。
- 最低延迟方案是 **Rules**，平均延迟为 0.241 ms，但开放任务覆盖与安全拒绝能力不足。

## 局限与可信边界

- 严格通过要求意图、参数、确认、动作、Workflow 和拒绝判断全部正确，因此该指标比单项意图准确率更严格。
- 本实验每种方案只运行一轮 80 条样本，尚未统计多次重复推理方差。
- Schema Prompt 包含完整能力目录，Token 和延迟明显高于自由 LLM；后续可通过能力检索和按需注入降低成本。
- 离线规划准确率不能替代真实飞行闭环验证；物理执行可靠性由独立的10 轮 ROS/PX4 实验评估。
- 模型输出解析失败案例：`hybrid`: workflow-051。该案例按失败计入，没有人工补跑或修改结果。
